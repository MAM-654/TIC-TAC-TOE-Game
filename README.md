# Tic Tac Toe Game 🎮

This Tic Tac Toe game developed with HTML, CSS and JavaScript.

In this game you should go through the following steps:

1. Enter the name of each player by clicking on the edit button at the bottom of players box.
2. After enter each players name and confirm that, you can click on Start New Game button to game start.
3. Enjoy your game! 😉

## Run 👨🏻‍💻

To run this game, just open "index.html" file on your browser.
